# Storage Estimator

A small Python program that estimates how much storage a set of files needs.
Built for CS-117 Introduction to ICT, Lab 11 (Git and GitHub).

## How to Run
python storage_estimator.py

## Example
Number of files: 10
Average size (MB): 250
Total storage needed: 2500.00 MB
